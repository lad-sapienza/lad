## Update of 23 October 2026

**The migration is complete: all BraDypUS applications hosted by LAD are now available in version 5**, at [bdus.lad-sapienza.it](https://bdus.lad-sapienza.it/).

Because of a security threat affecting the software of the old server, the version 4 server was **shut down earlier** than originally planned. **No data has been lost**: all installations, which are all based on SQLite and therefore fully contained in single archives, have been saved and preserved. They remain recoverable if needed.

The old version 4 addresses (bdus.cloud/db) are therefore no longer reachable. Anyone holding links or references to those addresses is invited to update them, using the version 5 applications listed below. Anyone noticing anomalies or malfunctions, or needing to recover material from the old installations, can write to Julian Bogdani (julian.bogdani@uniroma1.it).

## The original announcement (11 September 2026)

The migration of BraDypUS applications hosted on the LAD infrastructure was getting under way: from version 4, so far available at [bdus.cloud/db](https://bdus.cloud/db), to the new version 5, reachable at [bdus.lad-sapienza.it](https://bdus.lad-sapienza.it/). Anyone wanting to know more about what's new in version 5 — a new interface, an open REST API, specialist plugins for archaeology — can read the [presentation article on the LAD blog](https://lad-sapienza.it/it/blog/bradypus-v5/).

## Migration timeline

The original plan was to complete the migration by the end of 2026 and to take the version 4 instances offline into cold storage in April 2027. The migration has been completed, and the shutdown of the version 4 server, for the security reasons described above, has been brought forward.

This effort is part of LAD's long-term strategy for maintaining the research data deposited on its infrastructure.
