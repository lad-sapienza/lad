As of today, [LAD blog](/blog/) articles can be annotated openly and collaboratively, thanks to the implementation of the [Hypothesis web _client_](https://github.com/hypothesis/client).

On the right-hand side of the screen, while reading blog posts, a vertical bar appears, which can be opened and used to annotate the text, using a tool called [Hypothes.is](https://web.hypothes.is/). If you select some text, a small _pop-up_ will ask whether you want to annotate or highlight the text. If you choose to annotate, a writing panel will open on the right side of the screen. Using Hypothes.is requires creating an account on their website. This account is managed by Hypothes.is, not by LAD. The Hypothes.is platform is based on the web annotation standard developed by the [W3C Web Annotation Working Group](http://w3.org/annotation).

These annotations are public by default. Private annotations can only be viewed by the user who created them. All annotations, both public and private, have their own URL and can be accessed in various ways using the Hypothes.is API. Please tag your annotations with `lad` so that we can follow them more easily.

Please be aware that public annotations can be viewed by all users.

Over time, passages of text that have been annotated multiple times will appear highlighted in yellow. This feature can be used to aid reading, drawing attention to the most interesting passages, those that are hardest to understand, or those that could spark a discussion.

Happy reading and happy annotating!
